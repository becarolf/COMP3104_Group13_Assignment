Introduction to DevOps

COMP3104 is a DevOps course offered at George Brown College.
The course introduces students to the principles, methodologies,
and tools used in modern software development and IT operations.

What is DevOps?

DevOps stands for Development and Operations. It is a set of
practices and principles that promotes collaboration between
software developers and IT operations teams.

The primary goal of DevOps is to improve software quality,
accelerate development cycles, and ensure reliable software
delivery through automation and continuous improvement.

Key Concepts in DevOps

1. Version Control
Version control systems, such as Git, allow developers to track
changes in source code, collaborate with team members, and
maintain different versions of software projects.

2. Continuous Integration (CI)
Continuous Integration is a practice where developers frequently
merge their code changes into a shared repository. Automated
builds and tests help identify errors early in development.

3. Continuous Delivery and Deployment (CD)
Continuous Delivery ensures that software changes are tested
and ready for release. Continuous Deployment takes this further
by automatically releasing changes that pass the required checks.

4. Automation
Automation reduces repetitive manual tasks, improves efficiency,
and minimizes human errors during software development.

5. Collaboration
DevOps encourages communication and shared responsibility
between development, testing, and operations teams.

Tools Used in DevOps

Git - A distributed version control system used to track changes.

GitHub - A platform for hosting repositories and collaborating
on software development projects.

GitHub Actions - An automation tool that supports CI/CD workflows.

Docker - A containerization platform that allows applications
to run consistently across different environments.

Importance of Learning DevOps

Understanding DevOps prepares students for modern software
development environments where teamwork, automation, and
continuous improvement are essential.

Through practical exercises, students develop skills in Git,
GitHub, branching strategies, repository management, and CI/CD.

These skills are valuable for careers in software development,
DevOps engineering, cloud computing, and IT operations.
